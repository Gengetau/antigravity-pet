# Antigravity 桌面置顶迷你悬浮条 (`agy-hud-bar`)

无边框、置顶、高清抗锯齿的桌面迷你胶囊条，专为贴合 Antigravity 聊天输入框底栏设计，实时展示 4 项核心遥测：

`⚡ 当前对话 token/s  |  限额 剩余%  |  缓存 命中率%  |  上下文 占用 (占比%)`

## 启动与关闭

- **静默无黑框启动**：双击 `start-hud.vbs`
- **关闭悬浮条**：在悬浮条上 **右键 → 退出悬浮条**，或双击 `stop-hud.bat`

## 贴合输入框底栏技巧

1. 启动后，用 **鼠标左键按住悬浮条** 拖放到 Antigravity 聊天输入框左下角模型选择器右侧的空白处（坐标会自动记忆）；
2. **右键悬浮条 → 外观融合模式 → 无边框融合模式**，边框与底色将变为透明，文字直接融进输入框深色背景中；
3. 再点击 **右键 → 锁定当前坐标 (防误拖动)** 即可固定在原位，鼠标悬停还能查看限额重置倒计时、端到端速率与精确上下文 Token 数。
